# Sample images

The "Try one of these" gallery on the Analyze page reads `index.json` from this folder.
Create the files with the last cell of `ml/train_moon_mars_landforms.ipynb` (download `samples.zip`
from Kaggle's Output panel), then upload everything inside the zip here. The gallery stays hidden
until `index.json` exists.

Images: DoMars16k test set (Wilhelm et al. 2020, CC-BY-4.0), from NASA's Mars Reconnaissance
Orbiter Context Camera (NASA/JPL/MSSS), and LROCNet / lunar rockfall test images from NASA's Lunar
Reconnaissance Orbiter Camera (NASA/GSFC/Arizona State University).
